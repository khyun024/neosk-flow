STEP 0 · ATTRACT (대기화면)

화면을 터치해 동기화를 시작하세요

관람객 유입 화면. 터치하면 참여 코드 입력으로 넘어간다.

전환: 터치 → 1 코드 입력
스태프: STEP 0 라벨을 5회 연속 터치하면 코드 없이 시작
모든 이후 화면에서 70초 무입력 시 이 화면으로 복귀 + 입력 데이터 초기화
STEP 1 · CODE (참여 코드 입력)

참여 코드를 입력하세요

입장 시 받은 6자리 코드를 입력한다. 코드 1개당 1회만 참여할 수 있다.

예시 모드(서버 없음). 형식(6자리)만 맞으면 유효한 코드로 처리하고, 이 기기에서 한 번 쓴 코드는 다시 쓸 수 없다. 실제 개발 시에는 발급된 5만 개 코드 목록과 대조한다(키오스크 1대면 내장 목록, 여러 대면 서버 대조).
코드 규격: 혼동 문자(0·1·I·L·O) 제외 영숫자 31종 × 6자리 = 약 8.9억 조합 → 무작위 입력 통과 확률 1/17,800
스태프: STEP 1 라벨 5회 연속 터치 시 사용 기록 초기화(그 뒤 같은 코드 재사용 가능)
STEP 2 · ENTER (이름 입력)

이름을 입력하세요

입력한 이름은 STEP 6에서 멤버 보이스가 호명할 때 사용된다. 최대 10자, 한/영 전환 가능.

0 / 10
이름을 입력하세요
이름은 필수다(‘이름 없이 시작’ 없음). 버튼을 누르면 아래를 검사하고, 통과해야 다음으로 넘어간다.
· 완성된 글자만 — 초성·모음이 섞이면(ㅋㅋㅋ, ㅎㅇ, 박ㅅ) 불가
· 금칙어 차단 — 욕설·비속어·성적 표현·혐오 표현. 띄어쓰기(시 발), 반복(시발발), 글자 끼워넣기(시이발)까지 정규화·자모 분해로 검사
· 한글·영문 모두 허용. 영문 이름은 호격 조사(아/야) 없이 그대로 호명
금칙어 목록은 스크립트 상단 BANNED 배열에서 운영 중에도 추가·삭제 가능

STEP 4 · SYNC (공명 분석)

공명 주파수 분석 중…

약 2.6초 연출 대기 (원본: 레이더 애니메이션)
매칭 로직: 21명 멤버 각자의 실제 설문 답변(sig)과 일치 문항 수 최다 멤버 선정.
동률이면 고정 TIE 우선순위로 결정 → 같은 답이면 항상 같은 멤버 (결정적).
완료 → 5 결과 공개 자동 전환
STEP 5 · RESULT (결과 공개)
당신의 신호가 닿은 멤버 —
멤버 사진 구역 실제 전시 시 멤버 초상 이미지
다른 요소 오버레이 없음
헤드폰을 착용하세요
화면 구성: 상단 문구 + 멤버 이름(—) + 멤버 사진 + 헤드폰 착용 안내
삭제됨: 신호 일치 개수, 근접 신호(2·3위), 화면 QR코드
전환: 버튼 터치 → 6 보이스 (결과를 먼저 보여준 뒤 목소리 재생)
확인 필요: 화면에 띄우는 사진을 실제 인쇄될 포토카드 사진과 같은 컷으로 할지, 화면용과 인쇄용을 다르게 갈지
STEP 6 · VOICE (AI 보이스 링크)

— 의 목소리

매칭된 멤버의 목소리가 입력한 이름을 호명하며 메시지를 전한다. (실제: 녹음/AI 보이스 재생 — 이 버전에서는 텍스트로만 표시)

대사 구성: 호명(이름+아/야) → 자기소개 → 멤버별 고유 메시지
인쇄 포토카드 요소(화면과 별개): 멤버 초상, 국문·영문 이름, 친필 손글씨, 친필 사인, 카드 코드, QR
분기: 인쇄하기 → 7 인쇄 / 처음으로 → 0 대기 (데이터 초기화)
